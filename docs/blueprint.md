# **App Name**: Dream Captures

## Core Features:

- Hero Section: Full-screen background image/video with overlay text, tagline, and CTA button.
- About Section: Story of the photographer with timeline animation and display of awards, recognitions, and key achievements.
- Portfolio/Gallery: Filterable gallery with lightbox view, captions/location details, and lazy loading.
- Testimonials: Carousel/slider format with star ratings (optional) and client photos/logos.
- Services Section: Clear breakdown of available photography packages, add-on services, and FAQs.
- Blog Section: Articles covering behind-the-scenes, tutorials, tips, or recent event stories.
- Contact Section: Clean contact form, embedded map, and social media links.
- Booking Section: Interactive calendar for checking availability and inquiry form.
- Client Showcase (Private Gallery): Login-protected area for individual clients to view/download their photos.
- Newsletter Integration: Email capture form to collect leads for updates and promotions.

## Style Guidelines:

- Primary color: Soft, muted grey (#A9A9A9)
- Secondary color: Off-white or light beige (#F8F5F2)
- Accent Color: Teal (#008080)
- Serif heading fonts + clean sans-serif body text (e.g., Playfair Display + Lato)
- Minimalist photography icons (camera, aperture, tripod, flash)
- Grid-based with clear white space
- Subtle parallax on scroll, fade-ins and zooms for gallery, smooth page transitions

## Original User Request:
### 📸 Web Design & Development Prompt

**Project Title:**
Dream Captures – Photography Portfolio & Blog Website

**Objective:**
Design and develop a stunning, responsive portfolio and blog website for **Dream Captures**, a professional photography service. The site will showcase the brand's work, story, and testimonials with a visually captivating UI and subtle photography-themed animations. Later, Firebase will be integrated to upload and manage photos, videos, and blog content.

---

### ✅ Core Requirements:

1. **Brand Identity**
   - Design a clean, elegant **logo** for "Dream Captures".
   - Use a color scheme and font pairing that aligns with luxury, creativity, and emotion (moodboard optional).
   - Include subtle **photography-themed elements** (camera icons, shutter effects, overlays, etc).

2. **Website Structure**
   - **Home Page**: Hero section with tagline, background image/video, and CTA.
   - **About Page**: Bio, journey, and mission of Dream Captures.
   - **Portfolio Page**: Grid/gallery layout to showcase photo albums and videos (placeholder data for now).
   - **Testimonials Page**: Real client quotes with subtle transitions or carousel.
   - **Blog Page**: Clean blog layout to post behind-the-scenes, tips, or story entries.
   - **Contact Page**: Form with name, email, message; optionally integrate Google Maps.

3. **Animations**
   - Light parallax or scroll-based animations (e.g., fade-in galleries).
   - Hover effects on portfolio items.
   - Page transition animations.

4. **Responsiveness**
   - Fully responsive layout across mobile, tablet, and desktop.

5. **Scalable Backend (To Be Integrated Later)**
   - Firebase setup for:
     - Photo and video uploads.
     - Blog content management.
     - Testimonials storage.
     - Authentication for admin panel.

---

### 🛠 Tech Stack Suggestion

- **Frontend**: React.js + Tailwind CSS (or styled-components/SCSS)
- **Routing**: React Router or Next.js (if using SSR)
- **Animations**: Framer Motion or AOS
- **Icons**: Lucide, Font Awesome
- **Later Backend**: Firebase (Firestore, Storage, Auth)

---

### 🚀 Deliverables

- Fully functional front-end website.
- Placeholder images and content.
- Logo files in SVG/PNG.
- Clean, well-structured codebase (GitHub optional).
- Clear documentation on how to run locally and deploy (e.g., Vercel/Netlify).
